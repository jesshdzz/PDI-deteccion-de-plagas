#### Procesamiento Digital de Imágenes

# Procesamiento de imágenes de plantas para la detección de plagas.

Implementación de técnicas de procesamiento de imágenes que ayuden a mejorar la calidad de las imágenes y a obtener los descriptores requeridos por un sistema de detección de plagas.

El conjunto de datos que se utiliza para desarrollar el proyecto es: _New Plant Diseases Dataset_ (disponible en https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset).
